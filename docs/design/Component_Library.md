# EduCore Enterprise Component Library Specification

## 1. Buttons & Triggers
- **Primary Button**: `bg-blue-600 hover:bg-blue-500 text-white font-bold rounded-xl shadow-lg shadow-blue-500/25`
- **Secondary Button**: `bg-slate-900 hover:bg-slate-800 text-slate-200 border border-slate-800 font-bold rounded-xl`
- **Ghost Button**: `bg-transparent hover:bg-slate-800/50 text-slate-400 hover:text-white`
- **Danger Button**: `bg-rose-600 hover:bg-rose-500 text-white font-bold rounded-xl shadow-lg shadow-rose-500/20`
- **Success Button**: `bg-emerald-600 hover:bg-emerald-500 text-white font-bold rounded-xl shadow-lg shadow-emerald-500/20`

## 2. Card Components
- **Dashboard Stat Card**: Metric title, numerical value, percentage trend badge, and HSL icon container.
- **Feature Card**: Rounded-3xl background, top tag badge, icon indicator, description, and hover border glow.
- **Announcement Card**: Top category tag, title, paragraph summary, publish timestamp, and target audience label.

## 3. Data Tables
- **Header**: Uppercase 11px semi-bold slate-500 text with bottom divider.
- **Rows**: Alternating hover highlights (`hover:bg-slate-50/80 dark:hover:bg-slate-800/50`), font-mono ID columns, status chips, and action icon buttons.
